# Demo-Take-Photo-FMX
An FMX program that THREE ways to take snapshots with the video camera.  
The code was tested on Win and Android. It should also work on Mac.  
The code is analyzed in the "Delphi in All Its Glory" book.  
The Release build needs the [LightSaber](https://github.com/GabrielOnDelphi/Delphi-LightSaber) library; the Debug build also uses FastMM4 (on Windows) and the optional [Autopilot for Delphi](https://gabrielmoraru.com/my-delphi-code/autopilot-for-delphi/) bridge, which lets an AI assistant drive the running app.
